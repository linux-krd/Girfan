# دەخل و خەرج — تۆمارکردنی داهات و خەرجی ڕۆژانە (PWA)

ئەپێکی ساکار بۆ تۆمارکردنی داهات و خەرجی ڕۆژانە، وەک PWA. دەتوانرێت لەسەر مۆبایل و کۆمپیوتەر دابمەزرێت و بێ ئینتەرنێت کار دەکات. پێویستی بە build و هیچ پاکێجێکی دەرەکی نییە.

## تایبەتمەندییەکان

- **سێ زمان:** کوردی سۆرانی، فارسی و ئینگلیزی (ڕاست‌بۆچەپ و چەپ‌بۆڕاست)
- **سێ ڕۆژژمێر:** کوردی سۆرانی (ساڵی ٢٧٢٦ و مانگەکانی خاکەلێوە، گوڵان، جۆزەردان ...)، هەتاوی و زایینی
- **ژمارە و جیاکەرەوە:** ژمارەی کوردی (٠١٢٣)، فارسی (۰۱۲۳) یان ئینگلیزی. جیاکەرەوەی هەزارەکان «،» یان «,» بەپێی زمانی ئەپەکە
- **بڕ بە پیت:** لەژێر بڕی خەرجی ئەم هەفتەیە و کاتی نووسینی بڕ، بە هەر سێ زمانەکە
- **دراوەکان:** دینار، دۆلار، یورۆ، ڕیاڵ و تمەن (فاریزە تەنها بۆ دۆلار و یورۆ)
- **پۆلەکان:** پۆلی ئامادەکراو (خواردن، کافێ، گواستنەوە، کڕین، پۆشاک، کرێ، فاتورە، تەندروستی، خوێندن، قەرز، دیاری ...) و دروستکردنی پۆلی نوێ لەگەڵ ئایکۆن
- **ئاماری هێڵکاری:** هێڵکاری ستوونی داهات و خەرج بە فلتەری ڕۆژ، هەفتە و مانگ، لەگەڵ دابەشکردنی خەرج بەپێی پۆل
- **ڕووکارەکان:** ڕەسەن (لەگەڵ دۆخی تاریکی خۆکار)، کاهی، شین و زەیتوونی
- **یەدەگ (بەکئەپ):** پاشەکەوتکردنی فایلی ئێکسڵ (`.xlsx`) لەسەر ئامێر، ناردن بە ئیمەیڵ و گەڕاندنەوە لەو فایلە
- گەڕان لە تۆمارەکان و دەستکاری یان سڕینەوەی هەر تۆمارێک
- فۆنتی **وەزیرمتن** (Vazirmatn)

زانیارییەکان تەنها لە `localStorage`ـی وێبگەڕی خودی بەکارهێنەر پاشەکەوت دەکرێن و هیچ سێرڤەرێک نییە.

## فایلەکان

| فایل | وەسف |
|---|---|
| `index.html` | هەموو ئەپەکە (HTML و CSS و JS لە یەک فایلدا) |
| `manifest.json` | ڕێکخستنی PWA |
| `sw.js` | Service Worker بۆ کارکردنی بێ ئینتەرنێت |
| `icon-192.png`, `icon-512.png` | ئایکۆنەکانی ئەپ |
| `icon-maskable-512.png` | ئایکۆنی maskable بۆ ئەندرۆید |
| `apple-touch-icon.png` | ئایکۆنی iOS |

## کارپێکردن لەسەر ئامێری خۆت

PWA تەنها لەسەر `https` یان `localhost` دادەمەزرێت.

```bash
# یەکێکیان بەکاربهێنە
python3 -m http.server 8080
npx serve .
```

دواتر `http://localhost:8080` بکەرەوە.


## نوێکردنەوە

دوای هەر گۆڕانکارییەک لە فایلەکان، ناوی کاش (cache) لە `sw.js` بگۆڕە (بۆ نموونە `dakhl-khasj-v5`) تا بەکارهێنەران وەشانە نوێیەکە وەربگرن.

## فۆرماتی فایلی ئێکسڵی یەدەگ

یەک شیت (sheet) بەم ستوونانەوە: `ID, Date (YYYY-MM-DD HH:MM), Type (expense|income), Category, CategoryName, Amount, Note, Currency, Icon`.
گەڕاندنەوە زانیارییەکانی ئێستا بە ناوەڕۆکی فایلەکە دەگۆڕێت.

## تێبینی دەربارەی فۆنت

فۆنتی وەزیرمتن لە Google Fonts بار دەکرێت و دوای یەکەم جار بۆ دۆخی بێ ئینتەرنێت لە کاش هەڵدەگیرێت. بۆ سەربەخۆیی تەواو، فایلی `Vazirmatn.woff2` لەتەک پڕۆژەکە دابنێ و بە `@font-face` لە `index.html` بیبەستەرەوە.
